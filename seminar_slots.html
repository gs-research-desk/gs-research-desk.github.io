🎤 세미나 일정 잡기

구글 캘린더의 빈 시간 중 세미나 가능한 칸 — 1시간 · 08~16시 시작 · 점심 11~13시 제외 · 앞뒤 일정과의 이동 시간 반영.

⚙️ 연결 설정

주소·토큰은 GitHub 시크릿 SEMINAR_GAS_URL·SEMINAR_TOKEN 에 넣어 두면 배포 때 이 페이지에 들어가 어느 기기에서나 바로 쓰입니다. 여기 칸에 넣으면 이 브라우저에서만 그 값으로 덮어씁니다(비우고 저장하면 배포본 값으로 돌아감). 설치 방법은 gas/seminar_slots.gs 머리말 — Apps Script 새 프로젝트에 붙여넣기 → testSeminarSlots 1회 실행(권한 승인) → 배포(웹 앱, 실행: 나, 액세스: 모든 사용자). 토큰을 넣어야 막힌 칸에 일정 제목이 보입니다.
